## Pizza Sales Performance Analysis

An end-to-end data analytics project focused on analysing pizza sales performance, customer ordering patterns, product performance, and business trends using SQL Server and Power BI.

### Power BI Dashboard Preview

#### 1. Sales Overview


The overview dashboard provides insights into:

- **Total Revenue:** 817.86K
- **Average Order Value:** 38.31
- **Total Pizzas Sold:** 49,574
- **Total Orders:** 21,350
- **Average Pizzas Per Order:** 2.32
- Daily and monthly order trends.
- Sales contribution by pizza category and size.

#### 2. Best & Worst Sellers Analysis


This dashboard analyses product performance through:

- Top 5 pizzas by revenue.
- Top 5 pizzas by quantity sold.
- Top 5 pizzas by number of orders.
- Bottom 5 pizzas by revenue.
- Bottom 5 pizzas by quantity sold.
- Bottom 5 pizzas by number of orders.

### Tools & Technologies

- **SQL Server:** Data querying and analysis using SQL.
- **Microsoft Power BI:** Interactive dashboard development and data visualization.
- **DAX:** KPI calculations and business metrics.
- **Microsoft Excel:** Data inspection and preparation.

### Key Business Objectives

- Analyse overall revenue and order performance.
- Identify daily and monthly ordering trends.
- Understand sales contribution across pizza categories and sizes.
- Identify the best-performing and least-performing products.
- Present business performance through interactive dashboards.

### Project Outcome

Developed a two-page Power BI dashboard to transform pizza sales data into meaningful business insights and support data-driven decision-making.
